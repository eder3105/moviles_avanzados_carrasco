# Actividad Propuesta 02 - Gestión de Clientes Bancarios

## Requerimientos Funcionales

1. **RF-01: Registrar Cliente Natural**
   El sistema debe permitir registrar un cliente natural capturando sus datos personales (Nombre Completo y DNI) junto a sus datos bancarios generales.

2. **RF-02: Registrar Cliente Jurídico**
   El sistema debe permitir registrar un cliente jurídico capturando los datos de la empresa (Razón Social, RUC y Representante Legal) junto a sus datos bancarios generales.

3. **RF-03: Gestionar Datos Bancarios de Apertura**
   El sistema debe registrar automáticamente para cada cliente su Código, Dirección, Fecha de Registro, Número de Cuenta y Monto Mínimo de Apertura.

4. **RF-04: Listar y Mostrar Clientes Registrados**
   El sistema debe permitir visualizar en consola el detalle completo y formateado de todos los clientes registrados (tanto naturales como jurídicos) usando polimorfismo.
